# Industry-wise Agent Use Cases

One place to see **which industries already have an agent in this repo and which are still missing**. Each section lists what is covered (linked) and a **Wanted** checklist of distinct use cases nobody has contributed yet. Rare, niche use cases are welcome: a narrow, real problem beats another generic chatbot.

**How to contribute a "Wanted" item:** build or find an open-source agent that does exactly that, then open a PR following [CONTRIBUTION.md](CONTRIBUTION.md) (a row in the README Industry table, or a runnable agent under `agents/`). Tick the box in the same PR. Entries need a licence, recent activity, and working code.
